# Data Sources

Default word books are generated by `download_json_words.py`.

## CET4

- Source: KyleBing English Vocabulary, `json/3-CET4-顺序.json`
- URL: https://github.com/KyleBing/english-vocabulary
- Usage: deduplicated by lowercased word, keeping the richest available meaning entry.

## CET6

- Source: CET4 book plus endict CET6 supplement.
- endict URL: https://github.com/ismartcoding/endict
- endict notes: its README says CET4/CET6 vocabulary lists come from the 2016 national CET syllabus.
- Dictionary/phonetic lookup: endict dictionary data, derived from ECDICT.

## Kaoyan

- Source: exam-data NETEMVocabulary, `netem_full_list.json`
- URL: https://github.com/exam-data/NETEMVocabulary
- Notes: the source README describes a 2024 NETEM English I syllabus list of 5530 words, frequency-sorted from exam corpora with manually checked meanings.
- Data license: CC BY-NC-SA 4.0. Keep attribution, non-commercial use, and share-alike requirements in mind when distributing the generated default books.
